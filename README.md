This repository contains the executed prerequisite Colabs for the CMPE 255 refresher assignment. The focus is on refreshing the fundamentals needed to understand machine learning algorithms, tensors, optimization, and common AI model architectures.

## Neural Network Playground

The [Neural Network Playground](https://dlmastery.github.io/neural-network-playground/) is the separate non-Colab portion of the refresher. It provides interactive views for neural networks, CNNs, Transformers, graph neural networks, diffusion models, and architecture design spaces. The walkthrough connects the interface to the underlying ideas of representation, trainable parameters, nonlinear transformations, attention, message passing, denoising, optimization, and model capacity.
